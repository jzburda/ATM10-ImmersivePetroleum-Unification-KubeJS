ATM10 Immersive Petroleum Unification - KubeJS
 
Unifies Immersive Petroleums' Fluids with ATM10.
This fix does not balance Immersive Petroleum's fluids, only unifies them with the modpack so they work.

Installation:
1. On Curseforge, right click your ATM10 installation and click Profile Options. 
On Profile Options, click "Allow content management for this profile". Click Done.
2. Right click the profile and click "View Profile" Click "Content" and install Immersive Petroleum
3. Download LoonIP.js and install it into (Modpackfolder)\kubejs\Server_scripts\Unification
4. Start Minecraft, Immersive Petroleum's fluids should now have the C: tags on them and allow for processing recipes by other mods
